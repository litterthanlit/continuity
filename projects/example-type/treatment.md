# Treatment — example-type (v2 re-cut)

**Concept.** Six beats of type that argue one idea — agents can make motion you'd ship because
they can finally *see* it — set in the loudest honest voice a feed allows: condensed caps.

**Arc.** Hook (a claim designers agree with) → turn (agents can already write it) → tension (but
they're blind) → resolution (we gave them eyes: the contact sheet) → proof (every frame checked) →
brand. One line pair per scene; the argument reads even muted.

**Visual language.**
- Theme `mono-dark`, aurora backdrop, a single violet accent.
- Type kit **broadside**: Archivo at 66% width and 850 weight, all caps, tight leading (0.88) —
  the Figma Config / social-poster register. Condensed caps let each line run bigger in 9:16
  than a grotesk could.
- One emphasis per line, never two: a lowercase Instrument Serif italic word inside the caps
  (`craft.`, `eyes.`) — the contrast does the work; a marker bar under `WRITE`; `SEE` defocusing;
  a drawn check.
- Same left edge and baseline rhythm in every scene (`TypeStack`), so cuts read as one layout
  changing state. The end card breaks it on purpose — centred, but inside the social safe zone
  (clear of the platform's right-hand rail), not on the frame.

**Motion language.**
- Lines mask up (`maskUp` by line, `hero`), words punch on the turn (`rise` by words).
- Holds carry a slow camera push; nothing exits — the transition is the exit.
- One variable-axis moment, saved for the brand: the `CONTINUITY` wordmark settles from wide to
  its 66% width (`widthIn`, by chars).

**Transition language — kinetic punch.** Cuts on the beat between the argument's lines; two
accents where the story turns: a `punchCut` into the tension (*but they can't see it*) and into
the brand, and one vertical `whip` from blindness up into *so we gave them eyes*. Nothing else.

**Rhythm.** 2.3–2.9s per beat (the end card 3.2s), ~15s total. Punches on the turns, a breath on
the contact sheet, the end card holds ≥ 1.5s. After a punch, the incoming scene starts moving only
once the flash has landed.

**References.** Figma Config 2025 identity (condensed display), Vercel Ship type films,
Pentagram kinetic identities.
