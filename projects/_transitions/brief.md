# Transitions gallery (reference)

litt's transition language chained once, so each accent can be judged at its mid-point:
`npx ct stills _transitions --at <scene start + d/2>`.

A litt edit is mostly cuts on the beat. The accents are crossfade (the same surface in a new
state), dip (a chapter break), push / pushUp (sequential steps, motion blur when fast) and a
feathered wipe (a state revealed). Each scene names the transition that brought it in, on
alternating solid and lit stages with a flat raised surface on alternating sides, so mask edges
and motion blur are legible.

This is a reference reel, not a film: it deliberately breaks the one-transition-language rule
(`transition-language` warns) — a real video picks cuts plus one or two accents.
