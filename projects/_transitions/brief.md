# Transitions gallery (reference)

Every v2 scene transition chained once, so each can be judged at its mid-point:
`npx ct stills _transitions --at <scene start + d/2>`.

Each scene names the transition that brought it in and sits on a different background with a
big accent block on alternating sides, so mask edges, motion blur and light bands are legible.

This is a reference reel, not a film: it deliberately breaks the one-transition-language rule
(`transition-language` warns) — a real video picks one language of 1–2 types.
